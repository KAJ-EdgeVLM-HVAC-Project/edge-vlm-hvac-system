# 실험: 자체 촬영 사무실 영상 기반 검증

게재 논문의 실험 기록이다.

> 김준경, 김철호, 김민서, 정윤찬, 옥수열, 오지영, 이석환, 「비전-언어 모델 기반 엣지 냉난방 제어
> 프로토타입 설계」, *한국멀티미디어학회 논문지*, 제29권 제10호, pp.1789–1807, 2026.

## 1. 데이터와 평가 조건

| 항목 | 값 |
|---|---|
| 데이터 | 저자들이 직접 촬영한 실내 사무 환경 모니터링 영상 |
| 영상 | 고정 카메라, 1280×720, 30 FPS |
| 분석 구간 | 21,555초(약 359분), 30초 주기 VLM 추론 718회 |
| 재실 | 재실 비율 81.2%, 평균 2.2명, 최대 6명 |
| 환경 | 외기 32°C, 초기 실내 30°C (여름 냉방 시나리오, 시뮬레이션 설정값) |
| 제안 방식 | VLM·YOLO 인식 + PMV 기반 상태 제어 |
| 비교 기준 | 재실 중 고정 설정온도 22 / 24 / 26°C + Fan2, 공실 시 정지 |

고정 설정온도를 하나만 두지 않은 이유: 현장의 설정값은 과냉방에 가까운 22°C부터
공공기관 권장 26°C까지 폭넓다. 기준을 하나만 쓰면 그 값이 우연히 해당 재실 조건에
맞는지에 따라 비교 결과가 크게 달라진다.

원본 영상은 재실자 초상권 때문에 저장소에 포함하지 않는다. 대신 영상에서 얻은
**인식 결과 로그**([analysis_log_6h.csv](experiment/analysis_log_6h.csv))를 공개해,
제어·물리·에너지 계산을 누구나 재현할 수 있게 했다(아래 4절).

## 2. 에너지 모델

압축기 부하 기반: `P = P_fan + P_comp,rated × load`

| 파라미터 | 값 |
|---|---|
| 팬 전력 (1/2/3단) | 40 / 70 / 110 W |
| 압축기 정격 | 1,200 W |
| 부하율 load | 0~1, 실내 유입 열(외기 전도 + 체열) ÷ 냉난방 능력 |
| 건물 열시상수 τ | 3,600 s |
| 냉난방률 | 0.025 °C/s·fan |
| 재실자 체열 | 0.003 °C/s·인 |
| 적산 간격 Δt | 30 s |

부하율 상수는 `hvac_simulator.py`와 같게 맞춰 물리 모델과 전력 모델이 일관된다.
제안 방식과 기준선은 같은 시뮬레이터·전력 모델에서 병렬로 돌므로, 절대값보다
**상대 절감률**로 해석해야 한다. 실제 전력계 측정값이 아니다.

## 3. 결과

### 3.1 에너지·쾌적성

| 지표 | 제안 방식 | 고정 22°C | 고정 24°C | 고정 26°C |
|---|---|---|---|---|
| 총 에너지 | **1,382.7 Wh** | 1,742.0 Wh | 1,613.9 Wh | 1,485.9 Wh |
| 제안 방식 절감률 | — | −20.6% | −14.3% | −6.9% |
| 쾌적률 (PMV ±0.5) | **98.9%** | 92.4% | 98.5% | 7.1% |
| 쾌적률 개선 | — | +6.5 ppt | +0.3 ppt | +91.7 ppt |

쾌적률은 재실 중 PMV가 ±0.5 안에 든 표본 비율이다(공실 구간 제외). 제안 방식의
평균 실내온도는 24.39°C.

- **22°C**: 에너지를 가장 많이 쓰고도 92.4% — 과냉각으로 서늘한 구간 발생
- **24°C**: 쾌적률은 비슷(98.5%)하나 에너지 14.3% 더 소비
- **26°C**: 에너지는 가장 적지만 쾌적률 7.1% — 대부분 시간 더움

고정 제어의 쾌적률은 설정값 선택에 따라 7.1~98.5%로 흔들린다. 제안 방식은 그 선택과
무관하게 98.9%를 유지했다.

### 3.2 제어 요소별 기여도 (ablation)

동일 인식 로그에서 제어 요소를 하나씩 빼고 재시뮬레이션했다.

| 구성 | 에너지 | 절감 | 쾌적률 |
|---|---|---|---|
| 고정 24°C + Fan2 | 1,613.9 Wh | — | 98.5% |
| + 동적 목표온도·팬 제어 (상시 가동) | 1,385.9 Wh | 14.1% | 98.6% |
| + 쾌적 도달 시 압축기 정지 (전체 제안) | 1,382.7 Wh | 14.3% | 98.9% |

절감 대부분은 목표온도·송풍 조절에서 나온다. 압축기 정지의 몫이 작은 것은 재실 81.2%,
외기 32°C 조건에서 열 유입이 계속돼 냉방을 끌 수 있는 구간 자체가 적기 때문이다.

### 3.3 인식 결과

| 항목 | 모듈 | 결과 |

## 4. 재현 방법

인식 결과(clo·met·인원·외기)는 HVAC 상태와 무관하므로(카메라 영상만 봄), 로그를 다시
넣어 제어·물리·에너지만 재계산하면 같은 결과가 나온다. VLM·YOLO를 다시 돌릴 필요가 없어
6시간 분량이 수 초에 끝난다.

```bash
python report_multi.py docs/experiment/analysis_log_6h.csv out/
cat out/summary.txt      # 3.1절 표와 동일한 수치
```

| 파일 | 역할 |
|---|---|
| `replay.py` | 인식 로그 → 제어·물리·에너지 재시뮬레이션 |
| `report_multi.py` | 22/24/26°C 다중 기준선 비교 + 그래프 |
| `validate.py` | 실제 실행 로그와 재생기 결과 대조 검증 |

## 7. 한계

- 에너지는 실측이 아니라 전력 모델 기반 추정치
- 영상이 여름철 반팔·긴팔 착석 재실자에 편중, 외기 조건 단일 값 고정
- 옷차림·활동 정답 라벨이 없어 VLM 분류 정확도·JSON 유효율 정량 평가는 향후 과제

향후 계절·의복·활동이 고르게 포함된 데이터셋, 실측 기상 데이터 연동, 실제 공조기
장시간 제어로 보완할 계획이다.
