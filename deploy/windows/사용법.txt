===========================================================
 엣지 VLM 기반 지능형 HVAC 제어 시스템  -  Smart HVAC
 동아대학교 AI학과
===========================================================

[실행 방법]

  SmartHVAC.bat 를 더블클릭하세요.

  시작 화면에서 두 가지 중 선택합니다.

   1) 실시간 카메라 - PC에 연결된 웹캠으로 실시간 분석
   2) 영상 파일 분석 - 저장된 영상을 분석하고 그래프를 자동 생성
                      (동봉된 demo.mp4 로 바로 확인 가능)

  이어서 환경 프로파일(사무실/가정/체육시설/부대시설)을 고르면
  분석이 시작됩니다. 종료는 q 키입니다.


[처음 실행할 때]

  VLM 모델(약 1.9GB)을 메모리에 올리는 데 10~30초 정도 걸립니다.
  검은 창에 진행 상황이 표시되니 닫지 말고 기다려 주세요.

  Windows 보안 경고가 뜨면 "추가 정보" - "실행"을 눌러 주세요.
  (코드 서명 인증서가 없는 프로그램은 모두 이 경고가 표시됩니다.)


[화면 구성]

  운영자 대시보드 - 카메라 영상 + 인원/옷차림/활동/PMV/제어 상태
  사용자 리모컨   - 에어컨 리모컨 형태의 사용자 화면

  분석 결과는 results 폴더에 CSV와 그래프로 저장됩니다.


[동작 원리]

  카메라 영상
    -> YOLO26s (ONNX)        : 재실 인원 검출
    -> Qwen3-VL-2B (INT4)    : 옷차림/활동/공간/열원 인식
    -> ISO 7730:2005         : PMV 열쾌적 지수 계산
    -> 상태 기반 제어         : 전원/운전모드/목표온도/팬속도 결정
    -> 물리 시뮬레이터        : 실내 온습도 변화 재현
    -> 에너지 비교            : AI 제어 vs 고정 설정온도

  모든 추론은 이 PC 안에서 수행되며 영상은 외부로 전송되지 않습니다.


[폴더 구성]

  SmartHVAC.bat        실행파일
  python\             Python 런타임 및 라이브러리
  app\                프로그램 소스
  llama\               VLM 추론 엔진 (llama.cpp)
  models\              VLM 모델 (Qwen3-VL-2B INT4)
  app\yolo26s.onnx     사람 검출 모델
  demo.mp4             예제 영상
  results\             분석 결과 저장 폴더 (실행 후 생성)


[요구 사양]

  Windows 10/11 64비트
  메모리 8GB 이상 권장
  여유 공간 3GB 이상

  GPU는 없어도 동작합니다. NVIDIA GPU가 있는 PC보다
  VLM 분석 1회에 시간이 더 걸릴 뿐 결과는 같습니다.


[문제가 생기면]

  창이 바로 닫힌다
    -> 명령 프롬프트에서 SmartHVAC.bat 를 실행하면 오류 메시지가 남습니다.

  카메라가 안 잡힌다
    -> Windows 설정 - 개인 정보 - 카메라 에서 앱 접근을 허용하세요.
    -> 카메라가 여러 대면 시작 화면에서 선택할 수 있습니다.

  VLM 초기화에 실패한다
    -> llama 폴더와 models 폴더가 SmartHVAC.bat 와 같은 위치에
       있는지 확인하세요. 폴더째 복사해야 합니다.
